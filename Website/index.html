Three seconds, start to finish

1

Summon

CtrlSpace over whatever you are doing. Cairn captures that screen — and excludes its own window from the shot, so it never ends up answering questions about itself.

2

Ask

Type it, or speak. Words appear as you say them rather than after you stop — the audio streams while you are still talking, so you can see a mistranscription before it becomes the question.

3

Follow

The screen dims, a cursor lands on the control you need, and each step is spoken with captions. Esc stops everything, immediately, from wherever you are.

The second person asks for free

Most assistants answer the same question forever, and charge for it every time. Cairn keeps the answer as a trail — the steps, not the screenshot — and checks there first.

When somebody on your team has already found the setting, the walkthrough starts immediately and costs nothing. The model is only asked about things nobody has solved yet.

What it does not do

It is not watching

A screenshot is taken at the moment you ask, used for that one answer, and not stored. Nothing is captured while you are not asking.

It holds no keys

The API keys live on the server. The downloaded app has none in it, so unpacking the executable gets you nothing worth having.

It stays out of its own shot

The overlay is excluded from screen capture at the OS level. Without that, the model reads Cairn's own window and answers about Cairn.

It leaves nothing behind

One portable file, no installer, no registry writes unless you turn on Start with Windows yourself. Delete it and it is gone.

Questions you will hit in the first minute

Windows says it can't verify the publisher.

It can't — the binary is unsigned, because a code-signing certificate costs a few hundred dollars a year. Choose More info → Run anyway. The source is public if you would rather build it yourself.

I pressed Ctrl+Space and nothing happened.

Ctrl+Space is also the IME toggle for Japanese, Chinese and Korean input. If something already owns it, Cairn takes Ctrl+Shift+Space, then Alt+Space, then Ctrl+Alt+C — and tells you which one it got, in the panel and in the tray tooltip. If every one is taken, the tray icon still opens it.

Does it work in any app, or just a browser?

Any app. It is a desktop program, not an extension — it can see and draw on Figma, Excel, a VPN client, an installer dialog. That is the reason it isn't a web app.

I have two monitors.

It dims only the screen you asked on. The other one stays untouched, so documentation open on a second display doesn't get greyed out because you asked about the first.

Does it start with Windows?

Only if you ask it to, from the tray menu. A portable file that adds itself to startup uninvited is not behaving like a portable file.

What does it cost?

Nothing to download. Questions are answered by a hosted API, and answers that already exist as trails cost nothing to serve — which is most of them, once a team has been using it for a while.
